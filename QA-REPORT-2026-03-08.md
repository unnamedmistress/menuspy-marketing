## ⚠️ Issues Requiring Attention

### 🔴 CRITICAL: Security Vulnerability

**File:** `src/data/permitFees.ts:379`  
**Issue:** Use of `eval()` for dynamic formula calculation

```typescript
calculated = eval(formula);  // DANGEROUS!
```

**Risk:** Code injection vulnerability  
**Impact:** If `formula` is ever user-controlled, attackers can execute arbitrary code

**Fix Required:**
```typescript
// Use a safe expression evaluator like mathjs
import { evaluate } from 'mathjs';

const scope = { project_value, sq_ft };
calculated = evaluate(feeInfo.calculator.formula, scope);
```

**Action:** Replace `eval()` with `mathjs` or similar safe evaluator.
