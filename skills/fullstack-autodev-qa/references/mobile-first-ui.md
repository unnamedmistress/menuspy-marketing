# Mobile-First UI Standards

Use these standards when the skill is working on product UI.

## Layout

- Start with the smallest meaningful viewport first.
- Prefer simple vertical flow before adding dense side-by-side composition.
- Keep primary actions visible without requiring precision scrolling.
- Avoid layouts that only look balanced on desktop.

## Spacing

- Small screens need stronger spacing discipline, not merely smaller spacing.
- Group related information tightly and separate unrelated information clearly.
- Do not let cards, panels, or field groups blur together.

## Controls

- Primary actions should be obvious and reachable.
- Touch targets should be comfortably usable.
- Avoid tiny icon-only interactions unless context is extremely clear.

## Content

- Shorten copy on mobile if the current wording bloats the interface.
- Keep labels and helper text readable and direct.
- Do not let decorative UI crowd out task-critical information.

## States

- Mobile users need especially clear loading, error, empty, and success states.
- Missing states are a product-quality failure, not a minor omission.
