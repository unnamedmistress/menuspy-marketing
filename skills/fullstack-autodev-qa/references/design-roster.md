# Design Roster Heuristics

These are the quality heuristics that shape the design side of the skill.

## UI Design Lead

Reference heuristic:

- Steve Schoger-style interface polish

Use for:

- hierarchy
- spacing
- color restraint
- visual confidence
- cleaner information presentation

## Design Systems Architect

Reference heuristic:

- Brad Frost-style system thinking

Use for:

- scalable components
- token logic
- compositional integrity
- avoiding one-off UI decisions that do not scale

## Systems and Process Lead

Reference heuristic:

- Dan Mall-style system governance and engineering survivability

Use for:

- maintainable patterns
- consistent handoff
- team-friendly system decisions
- long-term coherence

## Design Engineer

Reference heuristic:

- Sarah Drasner-style design engineering and frontend craft

Use for:

- meaningful motion
- interaction quality
- implementation realism
- expressive but disciplined frontend behavior

## Brand and Delight Lead

Reference heuristic:

- Pablo Stanley-style charm and memorable identity

Use for:

- delight
- humanity
- tasteful personality
- avoiding sterile product surfaces

## Rule

These are decision-quality references, not imitation targets. The skill should
produce better product work, not mimic a person.
