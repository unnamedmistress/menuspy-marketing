# Concept 6: The "Pricing AI Co-Pilot" Chrome Extension

## Overview
A **Chrome extension** that overlays competitive intelligence directly on competitor websites while browsing.

## Problem Insight
Operators research competitors by visiting their websites directly — manual, time-consuming, outside the MenuSpy platform.

## Core Solution
When browsing a rival's menu, the extension shows: "MenuSpy has tracked 14 price changes at this restaurant in the last 90 days. See the full history."

## Target Users
- Primary: Active trial users and paying customers
- Secondary: Prospects browsing competitor menus (viral discovery)
- Tertiary: Restaurant consultants

## Delivery Model

### Extension Flow
1. Install from Chrome Web Store
2. On competitor site: Automatic restaurant detection
3. Overlay appears with 3 key data points
4. Click → opens MenuSpy dashboard with full analysis

### Key Features
- Price history mini-chart on hover
- "Add to Watchlist" button
- Screenshot tool with MenuSpy data overlay
- Share insight to Twitter/LinkedIn

## Pitch Site Structure

**Hero**:
- Headline: "See the invisible history of every menu you visit."
- Visual: Split-screen showing normal menu vs. enhanced view

**Sections**:
1. How It Works (video demo)
2. Key Features
3. Privacy & Security

## Visual Design

**Hero Image Prompt**:
> "A split-screen comparison of a fast-food website menu, left side normal, right side with futuristic overlay showing price trend charts and competitive intelligence data, cyberpunk aesthetic, glowing data visualizations."

## Implementation Notes
- Chrome Web Store publication required
- DOM scraping for restaurant detection
- Rate limiting for API calls
- Mobile companion app via QR bridge

## Strategic Value
- Meets users where they already work (browser)
- Provides value on competitor's turf
- Creates "aha moment" vs. manual research
- Viral discovery through shared screenshots
