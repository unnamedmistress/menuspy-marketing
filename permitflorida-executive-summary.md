# PermitFlorida — Executive Summary

## The Winning Concept
**PermitFlorida** — Florida's only building permit diagnostic tool, designed specifically for the state's 470 jurisdictions, hurricane zones, and flood requirements.

## Why Florida?
| Factor | Nationwide | Florida |
|--------|-----------|---------|
| **Jurisdictions** | 40,000+ | 470 (67 counties + 400 cities) |
| **Building Code** | Varies by state | Unified Florida Building Code (FBC) |
| **Update Cycle** | Irregular | Every 3 years (predictable) |
| **Construction Activity** | Baseline | 2x national rate |
| **Unique Requirements** | Generic | Hurricane/flood zones |

## The Problem (Research-Validated)
1. **No Florida-specific tool exists** — PermitFlow is commercial-only
2. **470 different rulesets** across counties and cities
3. **Hurricane/flood zone overlays** add complexity
4. **Homeowners are liable** when contractors skip permits
5. **Unpermitted work risks**: Fines ($250-500/day), insurance denials, sale complications

## The Solution
A webapp that answers one question: **"Do I need a building permit for my Florida project?"**

**User Flow:**
1. Enter zip code → identify jurisdiction
2. Select project type (FL-specific: impact windows, shutters, etc.)
3. Answer 5-7 questions (scope, DIY vs contractor)
4. Get instant YES/NO/MAYBE with confidence score
5. If YES → forms, fees, inspection timeline, contractor directory
6. Download PDF report for records
